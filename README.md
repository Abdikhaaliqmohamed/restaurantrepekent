# Restaurant Management System

A modern web-based restaurant management system designed to help manage orders, payments, tables, suppliers, users, and reports.

## 📌 Overview

This project provides a centralized dashboard for managing common restaurant operations.

The system is designed to organize restaurant data and provide an easy-to-use interface for day-to-day management tasks.

## ✨ Features

- Order management
- Payment management
- Table management
- Supplier management
- User management
- Reports and analytics
- Restaurant dashboard
- Responsive web interface

## 🛠️ Technologies

- TypeScript
- React
- TanStack Start
- Vite
- CSS

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Abdikhaliqmohamed/restaurant-management-system.git
```

Move into the project directory:

```bash
cd restaurant-management-system
```

Install dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Then open the local URL provided by the development server in your browser.
